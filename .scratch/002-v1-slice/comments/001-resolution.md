# Resolution

## V1 功能清单（Yk 定案，2026-08）

1. **双模式推荐都进 V1**：极速清场 + 饕餮盛宴。
2. **录入通道 = 文字 + 拍照**：拍照走「拍照→识别→人工确认修正→入库」，识别结果绝不直接入库（007 已证实 GLM-4.6V-Flash 免费视觉模型零成本起步）。**语音录入延后**至 V1 后迭代。
3. **案件卷宗完整版**：手动归档（做了什么菜、用了哪些食材）+ 评价，作为口味学习信号。
4. **赏味期限**：预置食材默认保质期字典，录入时自动带出、可改可跳过；「红色通缉令」= 3 天内到期高亮排序。
5. **多用户 + 共享冰箱完整做**：家人共用是核心场景；账号从简（用户名+密码，详见账号体系票）。
6. **统一食谱库**：平台一个公共食谱库（AI 批量生成种子起步）+ 用户自建（默认**私有可用**）+ 提交→**管理员审核**→过审对全平台公开；盛宴模式现场生成的食谱**存入私有**，想公开再走提交审核。
7. **审核工作流 V1 就上**：管理员角色（首个注册用户/本人），后台界面审核。

- 口味学习的自动化（V1 先靠手动评价积累信号）
