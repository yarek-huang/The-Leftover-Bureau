# Resolution

## 食材录入三通道交互（Yk 定案，2026-08）

### 文字录入

- **批量录入**：一次性多行表单（名字 + 数量 + 位置 + 状态 + 到期日），适合一次买完菜集中录。

### 拍照录入（008 已定识别只报名称+置信度，数量交人工）

- 流程：**拍 → 识别 → 逐条确认入库**（每条名称可改、数量手填、位置/状态/到期日选择）。
- 识别结果**绝不能直接入库**（002 闸门），每条必经人工确认/修正；识别全错可全清重来。
- **识别失败手兜底**：退回文字录入表单，预填识别出的部分名称供改。

### 录入后管理

- 食材列表**行内编辑/删除**。
- **手动标记"已用/丢弃"按钮**——即 004 决定的消耗/丢弃生命周期事件，触发留痕入冰箱历史。

### 红色通缉令呈现

- **首页聚合视图顶部独立面板**：跨冰箱汇总 3 天内到期列表，按到期远近排序。

### 移动端（做饭时看手机）

- **V1 两通道都响应式可用**（文字 + 拍照），拍照是手机端主入口。
- 术语对齐：Q7 答"三通道"含语音，但 002 已定语音延后出 V1；V1 实为两通道，语音在 V1 后迭代再上（不改变移动端通道齐全的意图）。
