## Question

实现 07 设计文档全部：信息架构 + 各页面 + 拍照流 + 推荐流 + 审核后台，移动端响应式、拍照为主入口。

关联设计文档：`docs/design/07-frontend-ia.md`（IA + 关键流程 + 徽章 + 响应式）、`012`（录入交互）、`002`（拍照为主入口）。

### 范围

- 顶部导航：首页聚合 / 我的冰箱 / 食谱库 / 我的食谱 / 卷宗 /（admin 多审核）右 +录入 / 用户。
- 首页聚合：红色通缉令面板（跨冰箱临期，带极速清场快捷）+ 聚合食材列表（单冰箱筛选 segmented control）+「给我推荐晚餐」盛宴入口。
- 我的冰箱：卡片列表（归档置灰带恢复）+ 单冰箱详情（食材/成员/邀请码/历史）。
- 食谱库：approved 浏览，荤素/难度筛，每卡片主料预览 + 用这个做。
- 我的食谱：列表（status 徽章 + rejected 理由）+ 新建表单（submit_for_review 选择）。
- 卷宗：做饭历史 + 记录卷宗入口。
- 录入：+录入 → 底部 sheet 双通道（拍照主入口 / 文字批量）→ 拍照流（020 接口）→ 确认 → 入库回首页刷新通缉令。
- 推荐：极速清场同步 loading → 套餐结果卡；盛宴异步轮询 → 套餐；LLM 失败报错 toast。
- 审核（admin）：待审列表 + 食谱全貌预览 + 通过/驳回填理由。
- 移动端响应式：底部 sheet、卡片堆叠、单列；桌面双列。
- 状态徽章颜色按 07 表。

### 验收

1. **临期五花肉**：首页 → 通缉令见五花肉(2天) → 极速清场 → 套餐结果。
2. **半颗卷心菜**：聚合列表见 → 给我推荐晚餐 → 盛宴匹配卷心菜食谱。
3. **不明剩菜盒**：+录入 → 拍照 → 改"红烧肉剩菜"+leftover → 入库 → 推荐带剩菜改造。
4. **审核**：admin 审核见妻子番茄炒蛋 → 预览 → 通过 → 食谱库立现。
5. 移动端竖屏全流程可用，拍照为主入口。
