# Resolution

## 账号体系设计（Yk 定案，2026-08）

### 注册与登录

- **V1：纯用户名 + 密码**，无邮箱字段、无手机号。
- **社交登录预留**：OAuth 提供商接口位（类似 provider 抽象层），V1 不实现；公网迁移后再接微信等。
- **注册为邀请制**：需现有用户生成注册邀请码方可注册（与冰箱邀请码是两套独立 token）。

### 找回密码

- **V1 不提供自助找回**：忘密码找管理员重置。

### 管理员角色（细化，已联动更新 013 票）

- admin **可转让、可任命多个**（首个注册用户=Yk 自动为 admin）。
- 任意 admin 可重置任意用户密码、审核食谱。

### 会话

- **JWT 无状态**（006 已定），允许多端同时在线，互不踢。

### 内网→公网安全升级钩子

- 环境变量切换：是否强制 HTTPS、密码强度校验、登录限流；内网阶段全关，迁移公网时一行开关打开。

## 域词汇（已同步 CONTEXT.md）

User、Admin（可转让/多任）、Registration InviteCode（注册邀请码，区别于 Fridge InviteCode）、OAuth Provider（社交登录预留接口）、JWT Session（多端在线）。
